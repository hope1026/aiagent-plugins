**제약**

- 브라우저 메뉴의 즉시 인쇄는 비동기를 기다리지 않는다. 미완료 도표는 원문을 보존하며, 문서의 인쇄 버튼은 전체 도표 준비 후 출력한다.
- 흐름 인식은 보수적이다. 공백이 있는 노드 이름은 각각 따옴표나 backtick으로 명시한다. 일반 설명은 원문으로 남긴다.
- 신규 웹사이트 여러 개의 미적 품질 benchmark와 실제 Claude Code·Antigravity discovery는 이번 변경 검증이 아니다. 모델별 품질을 보장하는 결과로 해석하지 않는다.
- 원격 release와 전역 설치는 실행하지 않았다. 현재 로컬 변경을 배포할 때 기존 version gate를 적용한다.
